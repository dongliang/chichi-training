# teddy-setup-training

训练我的小狗 Chichi。

**状态**：`index.html` 是一套完整的训练手册网站（Ian Dunbar 22 集讲义整理，5 章 30 课 + 30 个精选视频）。

在线版：https://dongliang.github.io/chichi-training/

打开方式：在线版直接访问；本地版建议起服务器（`python3 -m http.server 8000`），否则 `file://` 下 YouTube 内嵌会报错误 153，只能点封面跳转。

**资料**：`参考资料/ian-dunbar-dog-training/subtitles/` —— 22 份英文字幕（#007 时间轴损坏，#024/#025 抓取被 YouTube 拦截）。

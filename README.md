# teddy-setup-training

泰迪幼犬「布置 × 训练」一体化网页——把笼子/围栏尺寸、三区布局（LTCA）和如厕训练流程合成一个可交互页面。

## 怎么跑

单文件、零依赖，直接双击打开：

```bash
xdg-open index.html
```

或本地起个静态服务：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 页面内容

| 区块 | 内容 |
|------|------|
| **1. 布置** | 交互式俯视布局图：拖「成犬身长」、选围栏组合（10+2 / 12+2）、选笼子放里/放外 → 实时算走道余量、转身余量并给判定 |
| **2. 训练** | Dunbar 如厕 1-2-3（笼子 → 每小时 → 带笼外厕所 → 3 秒内奖励）；笼子 vs 围栏用哪个 |
| **3. 一天** | 10–12 周时间线（1 小时清醒 + 2 小时笼休） |
| **4. 别做** | 6 条常见错误 |

## 交互逻辑

- **围栏尺寸**由所选组合决定（120×80 / 90×110 / 60×140 / 120×110 / 90×140）。
- **走道余量** = 长轴 − 笼子 − 厕所（笼在内）或 长轴 − 厕所（笼在外）。
- **转身余量** = 短边 − 成犬身长。判定：≥15cm ✅ / 5–15 ⚠️ / <5 ❌。
- 判定规则：走道 ≥25cm 且转身 ≥15cm 才算「可用」。

## 数据来源

Ian Dunbar《Before You Get Your Puppy》（LTCA · Housetraining 1-2-3 · 3:1 长窄形）·
UC Davis《House-Training Your Puppy》（三区分离）· Pawsome Guides（三区布局 · 走道距离）·
Dogs Trust / Bestdog.au（笼＋围栏配合条件）· AVSAB（防过度依恋）· AKC（笼子买成年尺寸＋隔板）。

## 已知边界

- 走道/转身的阈值（25cm / 15cm）是**经验值**，来自「床厕所需 90–120cm 走道」和「短边要能转身」的换算，非硬标准。
- 页面不替代兽医意见；疫苗、健康问题请咨询执业兽医。
